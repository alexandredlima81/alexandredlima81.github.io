Casos de Uso

Route 53 - Health Checks com Routing Policy - Failover para Registros do tipo A (Address Records)

Este caso de uso configura o Amazon Route 53 para garantir alta disponibilidade de serviços, utilizando health checks e políticas de roteamento para gerenciar failover entre múltiplos IPs associados a registros do tipo A. A estratégia envolve monitorar a saúde dos IPs e redirecionar o tráfego automaticamente para um IP secundário em caso de falha do IP primário, garantindo continuidade e resiliência para aplicações críticas.

EC2 - Restaurando o Serviço SSH via User Data

Em situações onde uma instância EC2 sofre uma interrupção regional e é reiniciada automaticamente pela AWS, podem ocorrer falhas na inicialização de serviços críticos, como o SSH. Para contornar esse problema, o recurso User Data pode ser utilizado para garantir que o serviço SSH seja restaurado corretamente durante o boot da instância. Ao incluir um script de inicialização no User Data, como service ssh start, é possível assegurar que o acesso via SSH seja reestabelecido após reinicializações forçadas, mantendo a instância acessível.
